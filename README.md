# Virm

Сетевое ядро на Zig 0.16.0. Текущий реализованный этап: пул буферов,
ограниченные FIFO и TCP lifecycle; сетевой relay разрабатывается следующим.

## Подготовка окружения

После клонирования, с установленными Git и mise, из корня проекта:

```sh
mise install --locked
```

Команда устанавливает закреплённый Zig и автоматически подключает Git hooks.
С активированным в shell mise hooks также подключаются при входе в доверенный
проект. Сам `git clone` скрипты проекта не запускает.

Перед коммитом hook форматирует staged `.zig`/`.zon`, добавляет результаты
форматирования в index и запускает проверки форматирования, тесты Debug и
ReleaseSafe, сборку ReleaseSafe. Ошибки блокируют коммит.

Если staged Zig-файл содержит незастейдженные правки, hook останавливается до
форматирования: добавьте файл целиком или разделите изменения. Другие файлы
автоматически в index не добавляются.

```sh
mise run build
mise run check
```

`check` проверяет рабочее дерево без автоисправлений; в CI используйте его после
`mise install --locked`.
